# Banners da etapa de Ideação — Camp Food

Os cinco banners foram ajustados para que nenhum elemento ilustrativo invada a área dos textos.
O título e a descrição ficam em uma coluna à esquerda; as ilustrações ficam isoladas à direita.
A paleta mantém os azuis da identidade Camp Food, com detalhes verdes discretos.

Arquivos SVG:
- `banner-personas.svg`
- `banner-metamensagem.svg`
- `banner-mapa-objetivos.svg`
- `banner-htas.svg`
- `banner-molic.svg`

Os arquivos HTML permitem visualizar cada banner individualmente. Os documentos Markdown da pasta `02-ideacao/` continuam apontando para os SVGs.
